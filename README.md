# -PDF-
压一压是一个轻量、离线的图片与 PDF 压缩小工具。把截图、照片或 PDF 粘贴进来（也可以直接把文件甚至整个文件夹拖进窗口），选一个档位，就能当场看到压缩后的体积和原图/压缩后的效果对比；满意后导出文件，或一键复制到剪贴板直接去粘贴。它内置无损、高质量、平衡、极限四档预设和"目标体积"模式——PDF 默认只重压内嵌图片、完整保留文字与矢量（可选中可搜索），极限档会整页栅格化压到最小，并自动与"保留文字"的方案比大小取更优；图片会自动处理旋转与透明通道，截图类 PNG 还会智能换成无损 WebP。全程本地处理，不联网、不上传，绝不覆盖原文件；压缩结果会自动校验，异常就退回原文件。单个 exe，免安装，约 47 MB。
